# 構図・画角・視点：完成版

111カード・7装飾群・40選択肢です。デッキは含めていません。

## 読み込み

1. PromptGeneratorで現在の全データをExportし、バックアップを残します。
2. [構図・画角・視点を追加.html](構図・画角・視点を追加.html)を開き、現在の全データJSONを選びます。
3. 追加済みJSONを保存し、PromptGeneratorの全データImportで読み込みます。

既存のカード・装飾・デッキ・設定を保持します。同じIDまたは同じ英語のカードは追加を省きます。同じID・英語・フォルダのカードには不足する装飾の紐付けを補います。個別JSONのカードデータImport「追加」は装飾群を読み込まないため、補助ページを推奨します。個別JSONを全データImportすると既存データを置き換えます。

## 方針と使い方

写す範囲・見る方向・視点の高さ・配置・遠近感・画角やピント・一人称視点・反射・部分アップ・見切れ・複数人物・複数画面を分けました。既存の表情・視線やポーズは変更しません。

「全身」に「後ろから」「上から」「人物を左に」を装飾で付けるなど、必要なものだけ組み合わせます。「人物を左に」など配置のカードからも範囲・向き・高さを選べます。反射や複数人物にも適した装飾を用意しています。

膝上の基本カードと範囲の装飾は cowboy shot に統一しました。thigh-up shot は別カードにしていません。「膝上」の呼称と厳密な切り取り境界は必ずしも一致せず、注釈では太もも付近から上の範囲として説明しています。

「クローズアップ」の部位装飾は face close-up などの具体的な語を添えます。単独の部分アップカードも用意しています。「ズームレイヤー」「小窓の拡大図」には拡大する内容の装飾があります。

視線や目の状態は「表情・視線」を利用します。「pov hands」は品質側の任意除外候補にも存在するため、構図側では「first-person view, hands in foreground」として目的を明確にしました。人物の性別・年齢・服装・行為は固定していません。

装飾の選択は排他的ではありません。上からと下から、全身と頭の見切れなど、矛盾する指定は選び分けてください。複数人物・設定画・複数コマなどは外見や役割を維持できない場合があります。レンズ風・パノラマの指定は実際のレンズや出力画像サイズを変更する機能ではありません。
