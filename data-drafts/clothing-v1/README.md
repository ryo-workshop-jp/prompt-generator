1. 現在使っている環境で「全データ」をExportしてバックアップを保存する。

## 既存データへ追加する場合

「衣装_カード追加用.json」はカードを追加できるが、装飾は一緒に取り込まれない。
先に既存の装飾と新しい装飾を統合したファイルを作る必要がある。
今回は添付の現行JSONを読み取れていないため、既存データとの統合ファイルは未作成。
現行データを読み取ってから、IDと参照関係を保って統合する。

## 装飾の例

- シャツ + 赤 + 長袖 + 上のボタンを外す
  - red shirt, long sleeves, shirt with top buttons undone
- プリーツスカート + 赤 + 足首丈
  - red ankle-length pleated skirt
- ジップパーカー + 黒 + ジッパーを開ける
  - black zip-up hoodie, unzipped hoodie
- ブーツ + 茶 + 膝丈
  - brown knee-high boots

前置と後置それぞれで、装飾を選んだ順に結合される。
同一群から矛盾する候補を複数選ばない。実装は排他選択や英語の語順調整を行わない。
後置装飾は先頭にカンマを含め、独立タグとして接続する。
表示名にもこの単純結合が反映されるため、日本語は説明文として整形されない。
複数の衣服を一緒に指定すると、色や袖などが意図した衣服以外へ影響する可能性がある。
