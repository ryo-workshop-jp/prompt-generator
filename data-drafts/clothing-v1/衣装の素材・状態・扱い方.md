# 衣装の素材・状態・扱い方

マイクロブラ・マイクロショーツは衣装名だけに変更。年齢・性別は衣装カードに含めない。衣装を手に持つ、机に置くなどの用途にも使用できるよう、着用状態を別カードにした。

| カード | 英語 | 説明 |
|---|---|---|
| 不透明な生地 | opaque fabric | 透けない生地の指定。衣装の種類とは別に、必要なときだけ追加する。 |
| 乳首を覆った状態 | covered nipples | 衣装を着用し、乳首を覆う状態を指定する。持ち物や置かれた衣装には不要。 |
| 股部分を覆った状態 | covered crotch | 衣装を着用し、股部分を覆う状態を指定する。持ち物や置かれた衣装には不要。 |
| 衣装を着用する | wearing clothes | 衣装を身につけた場面の指定。具体的な衣装カードと組み合わせる。 |
| 衣装を手に持つ | holding clothing | 衣装を手に持つ場面の指定。着ている服ではなく持ち物として描きたいときに使う。 |
| 衣装を机に置く | clothing lying on a table | 衣装が机の上に置かれた場面の指定。人物に着用させる必要はない。 |
| 衣装をハンガーに掛ける | clothing on a hanger | 衣装をハンガーに掛けて見せる場面の指定。 |
| 衣装を畳んだ状態 | folded clothing | 衣装を畳んだ状態で描く指定。形の見え方は畳み方によって変わる。 |

これらは場面を組み立てるための候補。単独の汎用タグが特定の衣装だけに作用する保証はなく、画像生成による確認は未実施。各カードは必要なものだけ選び、着用と物としての配置を同時に選ばない。
