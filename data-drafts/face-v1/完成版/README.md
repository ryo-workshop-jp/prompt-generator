# 顔の特徴・表情の完成版

- `顔の特徴.json`：87枚、装飾5群・34候補。
- `表情・視線.json`：151枚、装飾3群・30候補。

表情・視線には目や口の状態、感情、視線、漫画表現、顔まわりの動作が含まれます。半目などにも瞳の装飾を使うため、瞳の色・瞳孔・ハイライトの装飾は両方のJSONに同じIDで含めています。統合時には1群ずつ保持します。カードの重複はありません。デッキは作成していません。

## 既存データを保持して読み込む

1. PromptGeneratorの現在の全データをExportし、バックアップとして保存します。
2. `顔と表情を追加.html` をブラウザで開き、そのExportファイルを選択します。
3. 追加済みJSONを保存して、PromptGeneratorの全データImportで読み込みます。

このHTMLには2つの完成JSONと同じカード・装飾を収録しています。既存の本文・注釈・設定を保持し、既存の顔カードは分類だけを更新します。既存の瞳孔装飾にも補完した4候補を追加します。ファイルは送信しません。

## カードだけを個別に追加する

各JSONを「カードデータ」の「追加」で読み込めます。この方法では装飾本体は追加されないため、装飾が未導入の場合は上記HTMLを使ってください。カテゴリ別JSONを「全データ」から直接読み込むと他のデータを置き換えるため、普段のデータへの追加には使わないでください。
