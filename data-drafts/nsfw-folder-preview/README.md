# 下着のNSFWフォルダ見本

衣装本体239枚は変更せず、成人向けの着崩しの見本4枚だけを追加する差分。デッキ・装飾データは含まない。

## 取り込み

1. 現在の全データをExportしてバックアップを保存する。
2. 設定の「カードデータ」Importで「下着_NSFWフォルダ見本_差分.json」を選ぶ。
3. Import方法は「追加」を選ぶ。「全データ」Importや「上書き」は使わない。
4. NSFW表示をONにし、衣装（初期データ第1案）→ 下着 → NSFW向け（着崩しの見本）を開く。

既存の親フォルダと同じIDを使うため、追加Importでは親フォルダを重複追加しない。新しい子フォルダと4枚のカードだけが追加される。

## 使い方

各カードに衣装と状態をまとめている。通常用の衣装カードと同時に選ぶ必要はない。マイクロブラの通常カードなどに状態を付け足す構成ではない。

成人の女性を明示し、不透明な衣服・下着で覆う構成に限定。乳首・性器の露出や性行為は指定しない。NSFWはこの見本を分けるアプリ上の表示分類。

JSONの構造と参照関係は確認済み。生成画像とブラウザーへのImportは未確認。
