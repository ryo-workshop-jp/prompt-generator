## 装飾も含めて追加する手順

1. PromptGeneratorから現在の全データをExportし、バックアップとして保存します。
2. [背景・ポーズ・動作を追加.html](背景・ポーズ・動作を追加.html)をブラウザで開き、ExportしたJSONを選びます。
3. 必要なカテゴリを選び、「追加済みJSONを保存」を押します。
4. 保存したJSONをPromptGeneratorの全データImportで読み込みます。

現在の全データが基準になります。既存のカード・フォルダ・装飾・デッキ・設定などを保持し、同じIDや同じ英語のカードは省略します。同じID・英語・フォルダの既存カードには、不足している装飾の紐付けだけを補います。既存の装飾は残します。修正前の背景を読み込み済みでも、このページで現在の全データを処理すれば反映できます。

個別JSONをカードデータImportの「追加」で読む方法もありますが、この方法では装飾群は読み込まれません。個別JSONを全データImportすると、既存データを置き換えるので注意してください。

## 収録方針

- SD1.5・SDXLのイラスト・アニメ用途向け候補です。実際の画像生成は未検証です。
- 性別・年齢・服装などは、カード自体の意味に必要な場合を除いて固定していません。
- 背景は場所と時間・天候・季節を分け、対応する場所だけに装飾を紐付けています。
- ポーズは身体の形、動作は行っていることを中心に分けています。「横になる」と「眠る」も別カードです。
- 学校内・店舗・住居・乗り物内などにも、時間帯・照明・内装・片付き方・人の多さを紐付けました。窓の外の天気は適した室内に限定しています。
- 座る場所・脚の形・持つ物・楽器・抱きしめ方などを装飾で選べます。
- 複数装飾は併用できますが、相反する向き・場所・形は利用時に選び分けてください。
- 明示的な性行為のカードは収録していません。デッキは未作成です。
- 注釈は特徴や場面の説明にしています。手指・複数人物の接触などの再現性はモデルにより異なります。
